# Security policy

## Supported versions

Only the latest release on the default branch is supported with security
fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's Security Advisories
for this repository. Do not disclose credentials, local paths, Herdr socket
contents, or an exploitable proof of concept in a public issue.

The plugin executes the Herdr CLI and user-selected shell hooks. Reports
involving command execution, path handling, state-file writes, or unintended
pane input are especially important.
